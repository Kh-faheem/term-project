Our Courses

The Computer Science Department offers a wide range of courses designed to build strong foundations and advanced skills in computing and software development.

Undergraduate Courses

  • Programming Fundamentals – Basics of programming and problem solving.
  • Object Oriented Programming – Classes, objects, and software design concepts.
  • Data Structures & Algorithms – Efficient data handling and algorithm design.
  • Database Systems – SQL, relational models, and database design.
  • Web Engineering – Frontend and backend web development.

Advanced & Elective Courses

  • Artificial Intelligence – Introduction to intelligent systems.
  • Software Engineering – Software development life cycle and project management.
  • Cyber Security – Fundamentals of information security.
  • Mobile App Development – Android and cross-platform development.
  • Cloud Computing – Modern cloud technologies and deployment.

Courses are offered every semester with a balance of theory, labs, and real-world projects.
